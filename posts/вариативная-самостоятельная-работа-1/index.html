Вариативная самостоятельная работа №1

Создание прототипа технического задания ИТ-продукта

1. Общие сведения

IT-продукт:
Веб-приложение для создания и изучения карточек («Учебные карточки»)

Тип продукта:
Одностраничное веб-приложение (SPA)

Цель разработки:
Создание удобного инструмента для хранения, редактирования и изучения учебных карточек, сгруппированных по папкам.

Целевая аудитория:

  • Студенты
  • Преподаватели
  • Пользователи, изучающие иностранные языки и термины

2. Основание для разработки

Основанием для разработки является необходимость в простом, локальном и независимом от внешних сервисов инструменте для обучения с использованием карточек (метод интервального повторения).

3. Назначение и функции системы

3.1 Назначение системы

Система предназначена для:

  • хранения учебных материалов в виде карточек;
  • структурирования материалов по папкам;
  • удобного изучения карточек в полноэкранном режиме.

3.2 Основные функции

  • Регистрация и авторизация пользователя
  • Создание, переименование и удаление папок
  • Создание, редактирование и удаление карточек
  • Просмотр карточек в сетке
  • Полноэкранный режим карточек с перелистыванием
  • Локальное хранение данных (LocalStorage)

4. Требования к системе

4.1 Функциональные требования

Пользователь:

  • Может зарегистрироваться и войти в систему
  • Может выйти из системы

Папки:

  • Создание папки
  • Переименование папки
  • Удаление папки
  • Перетаскивание папок для изменения порядка

Карточки:

  • Создание карточки (лицевая / задняя сторона)
  • Редактирование карточки
  • Удаление одной или нескольких карточек
  • Перетаскивание карточек
  • Просмотр карточек в полноэкранном режиме

4.2 Нефункциональные требования

  • Интерфейс должен быть интуитивно понятным
  • Поддержка современных браузеров (Chrome, Firefox, Edge)
  • Адаптивность интерфейса
  • Быстрый отклик интерфейса (без перезагрузки страницы)
  • Хранение данных без использования сервера

5. Требования к интерфейсу

5.1 Общий вид

  • Верхняя панель с названием приложения и пользователем
  • Боковое меню (burger-menu) для управления папками
  • Основная область для отображения карточек или папок

5.2 Карточки

  • В режиме сетки: пропорция 3:4
  • В полноэкранном режиме: пропорция 16:9
  • Автоматическое масштабирование текста под размер карточки

5.3 Контекстные меню

  • Кнопка в виде трёх точек (⋮) фиксированного размера
  • Контекстное меню для папок:
    • Переименовать
    • Удалить

6. Архитектура системы

6.1 Общая архитектура

  • Frontend: HTML + CSS + JavaScript
  • Архитектура: клиентская
  • Хранение данных: LocalStorage

6.2 Структура данных (пример)

{
  "user@email.com": {
    "password": "123456",
    "folders": {
      "Английский": [
        { "q": "Apple", "a": "Яблоко" }
      ]
    }
  }
}

7. Используемые технологии

  • HTML5
  • CSS3
  • JavaScript (ES6+)
  • LocalStorage API
  • GitHub (хранение и версионирование)

8. Ограничения и допущения

  • Работа без серверной части
  • Отсутствие синхронизации между устройствами
  • Данные хранятся только в браузере пользователя
